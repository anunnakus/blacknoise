# ЧЁРНЫЙ ШУМ

Сайт вымышленной индастриал-группы: рабочие плёнки, ритм-машина и печать обложек.
Один файл `index.html`, без сборки и зависимостей — весь звук синтезируется в браузере
через Web Audio API, вся графика рисуется на canvas.

## Что внутри

**Магнитофон БН-41.** Семь плёнок, каждая — живой дрон из шести осцилляторов, шума ленты
и пульсирующего суба. Шесть ручек с настоящей механикой: берёшь за обод — крутится по углу
руки, за центр — тянется вертикально, Shift даёт точную подстройку, двойной клик сбрасывает.
Стрелочные VU-приборы с пружинной физикой, осциллограф в трёх режимах, лампы, счётчик.
Катушку можно прижать пальцем — лента встаёт и питч уезжает вниз, крутнёшь по кругу — протяжка
идёт за рукой.

**Ритм-машина БН-808.** Шаговый секвенсор на 16 шагов, шесть синтезированных голосов плюс
дорожка своего сэмпла — с микрофона или брошенного на панель файла. Громкость шага 1–127
задаётся перетаскиванием клетки. Отдельная пунктирная дорожка дёргает эффекты: провал фильтра,
заикание, всплеск эха, краш, реверб, дырка в громкости. Панорама у каждого голоса, гейт на хвосте
реверба, биткрашер в петле эха, привязка времени эха к долям такта. 22 пресета из индастриала,
синтипопа, постпанка и танцевальных школ. Четыре банка и цепочка вида `A A B C` — из петли
собирается песня.

**Экспорт.** WAV считается офлайн быстрее реального времени со всеми настройками ручек.
MIDI — формат 0, канал 10, реальные велосити. Паттерн выгружается в JSON или пакуется в ссылку.

**Плакат.** Обложка собирается из паттерна: каждый удар — пятно, громкость — его плотность.
По центру фигура Лиссажу, соотношение которой берётся из числа ударов бочки и хэта.
Печать в четырёх форматах, вплоть до A4 в 300 dpi.

**Оформление.** Бумага с пятью слоями зерна, пыли и царапин, машинописный набор — каждая
литера со своим смещением и весом краски. Глобальная ручка ШУМ пачкает фон, трясёт текст
и подмешивает в звук ленточное шипение с треском и выпадениями. Курсор оставляет графитовый
след, клик впечатывает отпечаток ладони.

## Управление

| Клавиши | Действие |
|---|---|
| `Пробел` | плёнка: пуск/стоп |
| `←` `→` | предыдущая/следующая плёнка |
| `A S D F G H` | голоса ритм-машины |
| `J` | дорожка эффектов |
| `Shift` + клавиша | акцент |

## Запуск

Открыть `index.html` в браузере. Для микрофона нужен https или localhost:

```bash
python3 -m http.server 8000
```

## Публикация на GitHub Pages

1. Создать пустой репозиторий на GitHub.
2. В этой папке:

```bash
git remote add origin git@github.com:ПОЛЬЗОВАТЕЛЬ/cherny-shum.git
git push -u origin main
```

3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.

Через минуту сайт будет доступен по адресу `https://ПОЛЬЗОВАТЕЛЬ.github.io/cherny-shum/`.
В репозитории лежит и workflow `.github/workflows/pages.yml` — если включить Pages
в режиме `GitHub Actions`, публикация пойдёт автоматически при каждом пуше.
